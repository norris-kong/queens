# 每日題目與 Nightmare 由種子現場出題，不存檔

Daily Puzzle 以當天日期（香港時間）、Nightmare 的 Stage 以關數當種子，在玩家的瀏覽器裡用出題器現場產生，不寫進題庫。這樣不需要伺服器或每天的排程 commit，任何日期、任何關數都能隨時產生，同一天、同一關的所有玩家也都拿到同一題。代價是題目只由「種子 + 出題器」決定：改動出題器（或亂數產生器）就會讓同一天、同一關變成另一題；而進度以 Puzzle 的身份為鍵（見 0001），玩家當天或當關的進度也會跟著對不上。改出題器時要意識到這一點，必要時保留舊版本給既有的種子使用。

## Considered Options

- **每天用 GitHub Actions 排程出題並存檔**：題目永久固定、會經過題庫驗證，但 repo 每天多一個 commit，排程失敗當天就沒有題目，Nightmare 的無限關數也無法預先存檔。已否決。
- **每位玩家各自隨機出題**：最簡單，但玩家之間無法比較或討論同一題。已否決。
